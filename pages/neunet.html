What Is a Neural Network?

Understanding the biological inspiration and mathematical abstraction.

The Neuron

A neuron takes inputs, multiplies each by a weight, sums them up, adds a bias, and passes the result through an activation function.

y = f( Σ (wᵢ · xᵢ) + b )

where x=inputs, w=weights, b=bias, f=activation

Single Neuron Visualizer hover inputs to see flow
The Network Architecture

Neurons are stacked in layers: an input layer, one or more hidden layers, and an output layer. Together they form a feedforward network.

Interactive Network Builder
Neurons/layer: 4
🔵 Input Layer

Receives raw features. No computation — just passes data forward. Size = number of features.

🟣 Hidden Layers

Extract increasingly abstract representations. Each neuron learns a different pattern from its inputs.

🟢 Output Layer

Produces the final prediction. Size depends on task: 1 for regression, N for N-class classification.

Activation Functions

Non-linearities that let your network learn complex patterns.

Without activation functions, a neural network with any number of layers is equivalent to a single linear transformation — it can only learn linear relationships. Non-linearities are what make deep learning powerful.

ReLU

Most popular. Fast, avoids vanishing gradient.

f(x) = max(0, x)

Sigmoid

Squashes to [0,1]. Good for output probabilities.

f(x) = 1/(1+e⁻ˣ)

Tanh

Squashes to [-1,1]. Zero-centered, better than sigmoid for hidden layers.

f(x) = (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ)

Leaky ReLU

Fixes dying ReLU problem by allowing small negative outputs.

f(x) = max(0.01x, x)

Forward Pass

        
Computing predictions — one matrix multiplication at a time.

      

    


    

      The forward pass is how your network makes a prediction. Input → weighted sum → activation → repeat per layer → output.
    


    

      
 Matrix Form (Efficient Implementation)

      

        For a batch of inputs, we use matrix multiplication. For layer l:
      

      
Z[l] = A[l-1] · W[l] + b[l]

      
A[l] = f( Z[l] )

      
Z=pre-activation, A=post-activation, W=weight matrix, b=bias vector

import numpy as np

class NeuralNetwork:
    def __init__(self, layer_sizes):
        """
        layer_sizes: e.g. [2, 4, 4, 1]
        Means: 2 inputs → 4 neurons → 4 neurons → 1 output
        """
        self.weights = []
        self.biases  = []
        for i in range(len(layer_sizes) - 1):
            # He initialization for ReLU layers
            fan_in = layer_sizes[i]
            W = np.random.randn(fan_in, layer_sizes[i+1]) * np.sqrt(2.0/fan_in)
            b = np.zeros((1, layer_sizes[i+1]))
            self.weights.append(W)
            self.biases.append(b)

    def forward(self, X):
        """
        X: input matrix of shape (batch_size, n_features)
        Returns: output predictions
        """
        self.activations = [X]  # store for backprop later
        self.zs = []           # pre-activation values

        A = X
        for i, (W, b) in enumerate(zip(self.weights, self.biases)):
            Z = A @ W + b       # matrix multiply + bias
            self.zs.append(Z)
            # ReLU for hidden layers, sigmoid for output
            if i < len(self.weights) - 1:
                A = np.maximum(0, Z)     # ReLU
            else:
                A = 1 / (1 + np.exp(-Z)) # Sigmoid output
            self.activations.append(A)

        return A   # final output

Loss Functions

        
Measuring how wrong your network is — so it can get better.

      

    


    

      

        
📉 MSE — Regression

        

          Mean Squared Error — the average squared difference between predictions and targets.
        

        
MSE = (1/n) · Σ (ŷᵢ − yᵢ)²

        
Good for: house prices, temperatures, continuous values

      

      

        
📊 Cross-Entropy — Classification

        

          Binary Cross-Entropy is used for binary classification (0/1 tasks).
        

        
BCE = −(y·log(ŷ) + (1−y)·log(1−ŷ))

        
Good for: spam vs not-spam, cat vs dog, yes/no

import numpy as np

def mse_loss(y_pred, y_true):
    """Mean Squared Error for regression tasks."""
    return np.mean((y_pred - y_true) ** 2)

def mse_gradient(y_pred, y_true):
    """dL/dŷ for MSE."""
    return 2 * (y_pred - y_true) / y_true.shape[0]

def binary_cross_entropy(y_pred, y_true):
    """Binary Cross-Entropy for classification tasks.
    Clip predictions to avoid log(0)."""
    eps = 1e-8
    y_pred = np.clip(y_pred, eps, 1 - eps)
    return -np.mean(y_true*np.log(y_pred) + (1-y_true)*np.log(1-y_pred))

def categorical_cross_entropy(y_pred, y_true):
    """For multi-class. y_true is one-hot, y_pred is softmax output."""
    eps = 1e-8
    return -np.mean(np.sum(y_true * np.log(y_pred + eps), axis=1))

Backpropagation

        
The algorithm that makes learning possible — reverse-mode automatic differentiation via the chain rule.

      

    


    

      ⚠️ Backprop is often considered the hardest part of building a neural network from scratch. Take it slow. The key insight is the chain rule — we decompose the total gradient into a product of local gradients at each layer.
    


    

      
 The Chain Rule in Action

      
∂L/∂W[l] = A[l-1]ᵀ · δ[l]

      
∂L/∂b[l] = Σ δ[l]

      
δ[l] = (δ[l+1] · W[l+1]ᵀ) ⊙ f'(Z[l])

      
δ = error signal at layer l, ⊙ = element-wise multiply

    


    

      

        Backpropagation Flow — Gradients travel backwards

    def backward(self, y_true, learning_rate=0.01):
        """
        Compute gradients and update weights using backprop.
        Must call forward() first to populate self.activations and self.zs.
        """
        m = y_true.shape[0]  # batch size
        dA = self.activations[-1] - y_true  # output layer gradient

        for i in reversed(range(len(self.weights))):
            # Activation derivative (ReLU for hidden, sigmoid for output)
            if i == len(self.weights) - 1:
                dZ = dA  # sigmoid+BCE derivative simplifies to (ŷ - y)
            else:
                dZ = dA * (self.zs[i] > 0)  # ReLU derivative

            # Weight and bias gradients
            dW = self.activations[i].T @ dZ / m
            db = np.sum(dZ, axis=0, keepdims=True) / m

            # Propagate error signal backward
            dA = dZ @ self.weights[i].T

            # Gradient descent update
            self.weights[i] -= learning_rate * dW
            self.biases[i]  -= learning_rate * db

Optimization — Training

        
Gradient descent and its variants. How your network learns iteratively.

      

    


    

      

        

          
 Gradient Descent Variants

          
    
            
  • SGD — simplest, one sample at a time (or mini-batch)
    • 
            
  • Momentum — accumulates velocity, escapes local minima
    • 
            
  • RMSProp — adaptive learning rates per parameter
    • 
            
  • Adam — combines momentum + RMSProp. Default choice
    • 
            
  • AdaGrad — good for sparse data
    • 
          

        

        

          Rule of thumb: Start with Adam with lr=0.001. It almost always outperforms vanilla SGD out of the box.

class Adam:
    def __init__(self, lr=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        self.lr, self.beta1, self.beta2, self.eps = lr, beta1, beta2, eps
        self.t = 0   # timestep
        self.m = {}  # first moment (momentum)
        self.v = {}  # second moment (RMSProp)

    def step(self, params, grads):
        self.t += 1
        for key in params:
            if key not in self.m:
                self.m[key] = np.zeros_like(params[key])
                self.v[key] = np.zeros_like(params[key])

            # Update biased moment estimates
            self.m[key] = self.beta1*self.m[key] + (1-self.beta1)*grads[key]
            self.v[key] = self.beta2*self.v[key] + (1-self.beta2)*grads[key]**2

            # Bias correction
            m_hat = self.m[key] / (1 - self.beta1**self.t)
            v_hat = self.v[key] / (1 - self.beta2**self.t)

            # Parameter update
            params[key] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

import numpy as np

class NeuralNetwork:
    def __init__(self, layer_sizes):
        self.weights = []
        self.biases = []
        for i in range(len(layer_sizes) - 1):
            fan_in = layer_sizes[i]
            W = np.random.randn(fan_in, layer_sizes[i+1]) * np.sqrt(2/fan_in)
            b = np.zeros((1, layer_sizes[i+1]))
            self.weights.append(W)
            self.biases.append(b)

    def forward(self, X):
        self.activations = [X]
        self.zs = []
        A = X
        for i, (W, b) in enumerate(zip(self.weights, self.biases)):
            Z = A @ W + b
            self.zs.append(Z)
            if i < len(self.weights) - 1:
                A = np.maximum(0, Z)
            else:
                A = 1 / (1 + np.exp(-Z))
            self.activations.append(A)
        return A

    def backward(self, y_true, lr):
        m = y_true.shape[0]
        dA = self.activations[-1] - y_true
        for i in reversed(range(len(self.weights))):
            dZ = dA if i==len(self.weights)-1 else dA*(self.zs[i]>0)
            dW = self.activations[i].T @ dZ / m
            db = np.sum(dZ, axis=0, keepdims=True) / m
            dA  = dZ @ self.weights[i].T
            self.weights[i] -= lr * dW
            self.biases[i]  -= lr * db

    def train(self, X, y, epochs=1000, lr=0.01):
        losses = []
        for epoch in range(epochs):
            y_pred = self.forward(X)
            loss = -np.mean(y*np.log(y_pred+1e-8) + (1-y)*np.log(1-y_pred+1e-8))
            self.backward(y, lr)
            if epoch % 100 == 0:
                losses.append(loss)
        return losses

# ── Usage ───────────────────────────────────────────
X = np.array([[0,0],[0,1],[1,0],[1,1]])  # XOR data
y = np.array([[0],[1],[1],[0]])

net = NeuralNetwork([2, 8, 1])
losses = net.train(X, y, epochs=5000, lr=0.1)
print("Predictions:", net.forward(X).round(2))

import torch
import torch.nn as nn

# Same XOR problem — compare with your from-scratch version!
X = torch.tensor([[0.,0.],[0.,1.],[1.,0.],[1.,1.]])
y = torch.tensor([[0.],[1.],[1.],[0.]])

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 8),   # 2 → 8 neurons
            nn.ReLU(),
            nn.Linear(8, 1),   # 8 → 1 output
            nn.Sigmoid()
        )
    def forward(self, x):
        return self.net(x)

model     = Net()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
loss_fn   = nn.BCELoss()

for epoch in range(2000):
    pred = model(X)
    loss = loss_fn(pred, y)
    optimizer.zero_grad()   # clear old gradients
    loss.backward()          # autograd does backprop!
    optimizer.step()         # update weights

print(model(X).detach().round())
